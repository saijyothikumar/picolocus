# Agent Skills Repository (.agents/skills/)

Permissive open-source skills tracked for `@silent-mi` architecture, build, test, and optimization workflows:

- **hybrid-search-implementation** (MIT, wshobson/agents): Hybrid lexical + vector search, branch-and-bound pruning, and scoring fusion.
- **similarity-search-patterns** (MIT, wshobson/agents): Int8 quantization, cosine distance, and dimension-reduced projections.
- **performance-optimization** (MIT, addyosmani/agent-skills): Sub-10ms UI latency, `tbody` cache reuse, non-blocking Light DOM rendering.
- **security-and-hardening** (MIT, addyosmani/agent-skills): CSP/Trusted Types invariants, zero innerHTML, prototype pollution immunity.
- **accessibility-compliance** (MIT, addyosmani/agent-skills): Keyboard shortcuts (Ctrl+K, Enter/Shift+Enter), ARIA controls, non-focus stealing.
- **code-simplifier** (Apache-2.0, getsentry/skills): Minimal dependencies, zero unnecessary abstractions, anti-bloat principles.
- **agents-md** (Apache-2.0, getsentry/skills): Concise agent instruction standards without boilerplate.
- **transformers-js** (Apache-2.0, Hugging Face): Offline WASM worker pipelines, mean pooling, L2 normalization.
- **quantized-export** (Apache-2.0, Hugging Face): Dynamic QUInt8 ONNX quantization.
- **train-sentence-transformers** (Apache-2.0, Hugging Face): Hard negative mining, low-rank residual bottlenecks.
